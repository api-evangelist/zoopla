# Zoopla

> Zoopla Limited is one of the two dominant residential property portals in the United Kingdom, operating zoopla.co.uk alongside PrimeLocation under the Houseful group. Its public API surface is small and member-facing: a Leads API for polling consumer enquiries, a real-time lead Push service, and two product-activation APIs for Premium Listings and Weekly Featured Properties. The old public Zoopla listings API is retired and has no public successor. Documentation and all three machine-readable contracts are readable without a login, but credentials are not self-serve — you must already be a Zoopla member on a listings package, and client_id/client_secret are issued by Member Services after a GPG public-key exchange.

Generated by API Evangelist on 2026-07-26. Zoopla publishes no llms.txt of its own (https://developers.zoopla.co.uk/llms.txt returns 404); this file is generated from apis.yml and the artifacts in this repository.

Key facts an agent should know before calling anything:

- Auth is OAuth 2.0 client credentials against Amazon Cognito at https://services-auth.services.zoopla.co.uk/oauth2/token. Tokens are Bearer, expire in 3600s, and should be cached for their full lifetime — not caching them is the documented cause of HTTP 429.
- There is no sandbox and no test mode. https://services.zoopla.co.uk is production. The two POST operations spend real credits on a member's live contract.
- The activation APIs are asynchronous: POST returns 202 with a PENDING resource that must be polled until ACTIVATED or ERROR.
- There is no idempotency key. Duplicate activations are rejected by a natural-key guard on listingId (errors 1011003/1011004, 2011004/2011005) rather than replayed.
- There is no pagination anywhere, no versioning scheme, no request-id header, no published rate limit, and no changelog.
- Listings, property records, sold prices and valuations are NOT available through any public Zoopla API.

## APIs

- [Zoopla Leads API](https://developers.zoopla.co.uk/leads/reference/api): Poll applicant and appraisal leads generated on the portal. Two endpoints, two scopes, 30-day retention, 24-hour default window.
- [Zoopla Premium Listing Activations API](https://developers.zoopla.co.uk/premium-listings/reference/api): Activate the Premium Listing product on a listing, read activation history, check current premium status, patch the highlights chart.
- [Zoopla Weekly Featured Property Activations API](https://developers.zoopla.co.uk/wfp/reference/api): Activate the Weekly Featured Property product, read activation history, check current WFP status.
- [Zoopla Lead Push Service](https://developers.zoopla.co.uk/leads/docs/push-service): Outbound webhook that POSTs each lead in real time to an endpoint the member hosts. Zoopla is the client; the member is the server.
